# Ems Target
Ems approximates the Riemann zeta function by summing a series of terms, adding a basic correction term, and improving accuracy with higher-order refinements based on the Pochhammer symbol and a convergence check.

# Forward Spiral
Draws each summed element or “link” of the Riemann-Siegel function when \sigma = \frac{1}{2}. When \sigma \not= \frac{1}{2}, Euler-Maclaurin summation is used instead.

# Eta
The EtaFormula method approximates the Riemann eta function by summing an alternating series, where each term involves the cosine and sine of the logarithm of n weighted by powers of n. The summation is computed for a large number of iterations, refining the result by adjusting the real and imaginary components based on the given complex input s = a + bi.
