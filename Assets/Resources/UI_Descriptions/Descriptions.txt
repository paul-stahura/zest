# Index and Imaginary Input
Index is a change of variable.  It converts an index (which is a real number) to the imaginary component of the complex number input to the zeta function.
\\ t = I\left(T\right) = \frac{\pi\cdot\left(2T+1\right)}{\log\left(\frac{1}{T}+1\right)}
\\ This conversion is exact.

# Eta
The Eta function
\\Formula approximates the Riemann eta function by summing an alternating series, where each term involves the cosine and sine of the logarithm of n weighted by powers of n. The summation is computed for a large number of iterations, refining the result by adjusting the real and imaginary components based on the given complex input s = a + bi.
\\Note: Eta function has the same zeros as the Zeta function

# Gram Points
Gram points are specific values where the Hardy Z function changes sign.  The Gram points are defined by \theta(g_n)=n\pi. Gram's Law (which is not always true) states that the zeta function’s zeros alternate with the Gram points.
